Pick the right tool for the question you are asking.

LEOFF Helper now has a full planner plus three focused decision tools. Use the one that matches your question first, then move into the next step when you want more context.

Recommended flow

Start focused, then go broader.

Use a focused tool when you want a fast answer about timing, survivor protection, or pension value. Use the full planner when you want to see whether that answer still works inside the whole retirement picture.

If you are asking "Should I work longer?"

Start with Retirement Age Comparison, then validate the result in the Full Planner.

If you are asking "How much income would my spouse keep?"

Start with Lifetime Pension Value, then compare ages or build the full plan from there.
